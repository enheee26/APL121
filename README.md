APL121 — Бие даалт №1: Цагаан сарын бууз

Сэдвийн мэдээлэл

Сэдвийн дугаар: Сэдэв №2
Сэдвийн нэр: Цагаан сарын бууз
Оюутны нэр: Энх-Эрдэнэ Мөнхбаяр
Сургууль: Санхүү, Эдийн Засгийн Их Сургууль (СЭЗИС)


Миний тогтоосон дүрэм ба тариф (Rules & Rates)

Энэхүү бие даалтыг гүйцэтгэхдээ дараах тооцооллын дүрмүүдийг өөрөө тогтоож, ашиглав.

Гурилын орц: Нэг ширхэг буузанд дунджаар 15 грамм гурил зарцуулна гэж үзэв. Нийт гурилын хэмжээг буузны тоог 0.015 кг-аар үржүүлж тооцно.
Махны орц: Нэг ширхэг буузанд дунджаар 30 грамм татсан мах орно гэж үзэв. Нийт махны хэмжээг буузны тоог 0.030 кг-аар үржүүлж тооцно.
Бэлтгэх хугацаа: Нэг хүн 20 ширхэг бууз чимхэхэд нэг цаг зарцуулна гэж үзэв. Иймээс нийт буузны тоог 20-д хувааж, бэлтгэх хугацааг цагаар тооцно.
Шинийн 1–5-ны өдрийн хуваарилалт: Сар шинийн өдрүүдэд зочдын ирэх урсгалаас шалтгаалан өдөр бүр бэлтгэх буузны тоог хүснэгтээр харуулж, for давталт ашиглан хэвлэнэ.
Эрэмбэлэлт: Өөрийн болон өөр хоёр айлын буюу нийт гурван айлын бэлтгэх буузны тоог if нөхцөл ашиглан ихээс бага руу эрэмбэлж хэвлэнэ.


Заавал хэрэгжүүлэх 7 элементийн биелэлт

Оролт, гаралт: scanf() функц ашиглан зочдын тоо, нэг хүнд ногдох буузны тоо болон гурван айлын буузны тоог оруулна. Харин printf() функцээр үр дүнг хүснэгт хэлбэрээр хэвлэнэ.
Үйлдэл ба илэрхийлэл: Арифметик болон логик (&&, ||) үйлдлүүдийг хослуулан ашиглана.
Нөхцөл: else if шаталсан нөхцөл болон if нөхцөл ашиглан буузны тоог ангилна.
Давталт ба хүснэгт: Шинийн 1-ээс 5-ны өдрүүдийн хүснэгтийг for давталт ашиглан хэвлэнэ. Мөн %-10s, %6.2f зэрэг форматын хувиргагч ашиглан хүснэгтийн багануудыг жигд байрлуулна.
Дэд алгоритм: Flowgorithm програм дээр тусдаа функц үүсгэж, түүнийгээ дуудаж ашиглана.
Эрэмбэлэлт: Гурван айлын бэлтгэх буузны тоог ихээс бага руу эрэмбэлэх логик хэрэгжүүлнэ.
Оролтын шалгалт: Сөрөг тоо зэрэг буруу утга оруулсан тохиолдолд do-while давталт ашиглан алдааг шалгаж, зөв утга дахин оруулахыг хүснэ.
